**Goal:** Make the actual desktop service host the existing normal registry protocol with its own validated certificate, while preserving the standalone CLI.

**Architecture:** Move the existing registry dispatcher/storage into a reusable in-process runtime. Supply a bound listener, validated transport and explicit state directory; retain command parsing and legacy pairing in the standalone wrapper. This is the controller runtime prerequisite, not the complete pairing session or live trust-update implementation.

**Tech Stack:** Rust 2024, existing rustls transport, standard-library TCP/threads, existing registry persistence and process tests.

## Ancestor implementation contract

Continue Task 2 in `src/state_paths.rs`, with Windows-specific authority inspection in `src/state_paths/windows.rs`, and export the shared module from `src/lib.rs`. The two public operations are `validate_state_directory(&Path) -> io::Result<PathBuf>` (read-only) and `prepare_private_state_directory(&Path) -> io::Result<PathBuf>` (revalidate and privately create missing components). Both return the resolved absolute path; callers must actually use it. This design was independently reviewed for the other-local-account and untrusted-network threat model, excluding malicious same-user processes and privileged administrators. It does not replace final store-file link handling.

- Reject parent traversal instead of lexically collapsing `..` across potential links. Resolve relative standalone paths against a captured current directory; accept normal components and ordinary `.`. Handle all non-NotFound metadata or ACL errors as failures.
- Inspect components from the filesystem root. On Unix, require current-user or root ownership and reject group/world-writable ancestors except root-owned sticky directories whose children are independently verified. Accept system aliases only when the alias and its replacement authority are system-controlled; validate destinations recursively and share a maximum-16 redirect budget. User-controlled imitation aliases fail. Do not canonicalize an unchecked complete user path.
- On Windows, the volume root is the OS anchor. Inspect directory metadata and authority through opened handles; reject every reparse point in this first supported policy. Ordinary owner admission is current user, SYSTEM, Administrators or TrustedInstaller. Evaluate current-object ACEs, ignoring INHERIT_ONLY. Parent DELETE_CHILD or ACL-control rights granted to other accounts, and child DELETE or ACL-control rights granted to other accounts, invalidate the chain. Add-sibling rights alone do not mean an existing checked child can be replaced. Unsupported dangerous allow ACEs fail closed; do not infer safety by subtracting deny ACEs. A SYSTEM owner does not imply system-only control when the current user has full control.
- Create missing directories one immediate component at a time only after establishing a stable existing parent.
